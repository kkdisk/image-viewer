# v2.5 驗證紀錄

日期：2026-10-18。候選版本：`2.5.0`。發布前補充審查、安全修補與 CI 門檻見 [Code Review](V2_5_REVIEW.md)。下方的 EXE 啟動及效能紀錄來自先前開發版，不作為正式打包成品的驗證證據。

## 已完成的功能

- 五項調整參數產生獨立預覽，套用才建立一筆歷史；取消與中性參數套用不污染歷史。
- Undo／Redo 共用 20 步預算，追蹤儲存狀態，快照讀寫失敗保留既有紀錄。
- 原圖與目前結果並排比較，支援唯讀參考圖片、EXIF 方向校正、同步／獨立縮放平移。
- 開檔、媒體導覽、儲存、一般效果與關閉前，統一處理待處理調整。
- 輸出檔案先在同目錄完成編碼再取代目標，測試 PNG 透明度、ICC／EXIF 與 JPEG 白色背景。

## 大圖元件效能量測

環境：Intel64 Family 6 Model 158 Stepping 10、12 個邏輯核心、31.81 GiB RAM。啟用目前環境的 Rust 擴充模組；以 20ms 間隔採樣整個程序 RSS。

資料為合成 RGBA 橫向色帶，PNG 壓縮相對容易。量測涵蓋模型、調整控制器與比較視圖，不含完整主視窗的直方圖與 Filmstrip，也不代表相機照片、網路磁碟或所有 codec 的實際操作時間。

| 項目 | 24MP（6000×4000） | 48MP（8000×6000） |
| --- | ---: | ---: |
| 原圖快照 | 0.211 秒 | 0.420 秒 |
| 連續送出五次調整至最新預覽完成（合併中間請求） | 1.200 秒 | 2.405 秒 |
| 套用調整 | 0.496 秒 | 1.015 秒 |
| 比較視圖轉換與繪製 | 0.285 秒 | 0.598 秒 |
| 建立 20 步編輯歷史 | 5.158 秒 | 10.247 秒 |
| 一次 Undo 加一次 Redo | 0.572 秒 | 1.102 秒 |
| 峰值程序 RSS | 607 MiB | 1303 MiB |

48MP 的記憶體使用仍高，完整解析度預覽與磁碟歷史也有可見成本；正式發布前需以真實照片量測完整 UI，評估低解析度快速預覽及歷史 I/O 非同步化。
