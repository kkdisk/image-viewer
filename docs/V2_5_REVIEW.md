## 驗證結果與發布順序

- 本機 Python 3.10.11／PyQt6 6.11 的 offscreen 全套測試：184 passed。
- 致命錯誤 lint：0；一般 lint 仍有既有的 8 項複雜度警告。
- `pip check` 通過。Python 稽核不包含無 PyPI 發行資訊的本機 Rust 二進位；因此另查 Cargo.lock 並要求 Windows CI 重新編譯。
- 本機缺少 MSVC linker，修補後 Rust 二進位的編譯、完整 Windows 測試及正式 EXE 打包交由 Windows CI；未以舊二進位當作新版本的驗證證據。
- 先提交／推送 main，確認該 commit 的 Ubuntu 與 Windows jobs 通過後，才建立及推送 v2.5.0 標籤。CI 結果以 GitHub Actions 對應 commit 的 run 為準。

## 安全與驗證邊界

結論限於已檢查的程式路徑、測試案例與查詢當時的公開漏洞資料庫，不代表所有 bug 或未知漏洞都不存在。未引入遠端執行、shell 組字命令或上傳圖片功能；圖片輸出仍採同目錄暫存及原子取代，壓縮檔暫存圖片仍須另存至外部。

Windows 高 DPI／雙螢幕的主觀互動品質、全部媒體 codec、完整原生函式庫漏洞涵蓋率，以及真實大圖長時間壓力測試仍有驗證邊界。48MP 合成元件測試曾達約 1.3 GiB RSS；像素上限只提供配置邊界，不保證所有機器皆不會記憶體不足。

目前審查未留下已確認而未修補的 v2.5 發布阻擋項；正式標籤仍以對應 commit 的 CI 成功為條件。
